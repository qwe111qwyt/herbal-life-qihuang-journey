# 本草浮生 岐黄问道 H5 成品



## 体验内容

- 封面：点击启卷按钮进入序章；标题与体验说明位于右上方。
- 序章：药柜先擦开约一半灰尘，再按住药屉按钮进入第一章（实际仍需持续 1.2 秒）。
- 第一章：采摘六味本草，对照鲜株与干材，辨认四气五味后在居中弹框复习。
- 第二章：拖动药材进入药炉，完成三组君臣佐使配伍；药炉与投放区下移 56.7 CSS px。
- 第三章：完成甘草、黄芪、当归和黄连的炮制判断；药杵与药炉整体下移 56.7 CSS px，结章时师傅以原始亮度、不透明显示。
- 第四章：阅读两份非现实脉案，体验八纲辨证的思维方向；人物位于左侧。
- 终章：拖动今昔滑杆，生成学徒体验档案。

## 工程特性

- 原生 HTML、CSS、JavaScript 与 GSAP 时间线。
- 9:16 移动端舞台，桌面端居中显示，支持安全区。
- 封面右上角展示标题与体验说明，不再显示文字印章。
- Canvas 擦拭、Pointer Events 拖放、状态存档、静音与低动态模式；《宁静闲适》从首次交互起在整个体验中低音量连续循环，后台或静音时暂停。
- 素材全部本地化，可生成离线静态构建产物。
- 所有知识内容均明确标注为文化知识演示，不构成医疗建议。

## 运行

```powershell
npm.cmd install
npm.cmd run dev
```

生产构建：

```powershell
npm.cmd run build
npm.cmd run preview
```

自动化测试：

```powershell
npm.cmd run test:e2e
```

## 素材说明

交付目录中实际只有三张行走帧，所以项目采用 `walk_01` 至 `walk_03` 三帧循环，不伪造 `walk_04` 至 `walk_06`。正式补齐后三帧时，只需放入 `public/assets` 并扩展 `src/game-data.js` 中的 `walks` 数组。
